# Безопасный HTTP-клиент

Parent: [[Index]]

## Назначение

Общий HTTP-клиент движка для недоверенных адресов. Адреса приходят из метаданных реестров, llms.txt, страниц сайтов и из запросов на добавление библиотек. Клиент не допускает обращений во внутреннюю сеть на трёх уровнях: проверка URL, фильтрация результатов DNS и проверка каждого редиректа.

## Источники

| Файл | Значимый символ | Роль |
|------|-----------------|------|
| `backend/barkdocs-engine/src/http.rs` | `check_url` | Схема, учётные данные, порт, тип адреса |
| `backend/barkdocs-engine/src/http.rs` | `PublicResolver` | Оставляет только публичные IP после DNS |
| `backend/barkdocs-engine/src/http.rs` | `SafeClient::new`, `page`, `json` | Клиент с политикой редиректов и лимитом тела |
| `backend/barkdocs-engine/src/http.rs` | `is_public_ipv4`, `is_public_ipv6` | Классификация адресов |

## Публичные контракты

| Контракт | Поведение и условия |
|----------|---------------------|
| `check_url(url)` | Только `http` и `https`; без логина и пароля; без нестандартного порта; адрес — домен или публичный IP |
| `SafeClient::page(url)` | `None` при 404 и 410; ошибка при прочих неуспешных статусах; тело не больше 64 MiB |
| `SafeClient::json(url)` | То же, плюс разбор JSON |
| `read_page(response)` | Читает тело с лимитом; `is_html` определяется по `Content-Type` |

Таймауты: соединение 10 секунд, чтение 60 секунд, страница 30 секунд (задаёт вызывающий код через `timeout`). Пять редиректов максимум; каждый проверяется `check_url`. User-Agent: `BarkDocsBot/0.1`.

## Зависимости и взаимодействия

- Используется [[Engine/Sources|Источниками]] и [[Engine/Discovery|Поиском библиотек]] (проба llms-файла в `discovery.rs`, `register`).
- Не используется шлюзом: межсервисные вызовы идут через отдельный клиент `reqwest` в [[Web/Gateway|Gateway]].

## Ограничения и важные детали

- Прокси отключён: иначе адрес разрешил бы прокси, и фильтр DNS не сработал бы.
- Тесты в `http.rs` покрывают внутренние адреса (в том числе IPv4-mapped IPv6 и 6to4), схемы, порты, учётные данные и публичные адреса.
- Для IPv6 разрешён только глобальный unicast `2000::/3`, кроме документационного `2001:db8::/32` и 6to4 `2002::/16`.

## Решения и основания

- Фильтрация на трёх уровнях. Основание: описание модуля в `http.rs` — адреса недоверенные, поэтому проверка выполняется на каждом шаге.
- Отключённый прокси. Основание: комментарий в `SafeClient::new`.
