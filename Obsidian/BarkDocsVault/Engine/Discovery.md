# Поиск библиотек

Parent: [[Index]]

## Назначение

По имени или ссылке находит кандидатов в npm, crates.io и PyPI и регистрирует библиотеку с её источниками в [[Engine/DocsEngine|движке]]. Ссылки GitHub и сайты документации принимаются напрямую.

## Источники

| Файл | Значимый символ | Роль |
|------|-----------------|------|
| `backend/barkdocs-engine/src/discovery.rs` | `search_registries` | Опрос трёх реестров параллельно, отбор до трёх кандидатов |
| `backend/barkdocs-engine/src/discovery.rs` | `from_npm`, `from_crates`, `from_pypi` | Разбор метаданных реестров |
| `backend/barkdocs-engine/src/discovery.rs` | `from_link` | Кандидат по прямой ссылке |
| `backend/barkdocs-engine/src/discovery.rs` | `register` | Создание библиотеки, выбор источников, запуск первой синхронизации |
| `backend/barkdocs-engine/src/discovery.rs` | `valid_package_name` | Защита от мусора в запросе |

## Публичные контракты

| Контракт | Поведение и условия |
|----------|---------------------|
| `search_registries(name)` | Кандидаты из npm, crates.io и PyPI; недоступный реестр пропускается. Не более трёх, без дубликатов по репозиторию |
| `from_link(url)` | GitHub-ссылка становится репозиторием, остальные http(s)-адреса — сайтом. Адрес проходит `check_url` |
| `register(candidate, alias)` | Возвращает slug или `None`, если рабочих источников не осталось |
| `valid_package_name(name)` | Не более 100 символов: латиница, цифры, `-_.@/` |

## Зависимости и взаимодействия

- Использует [[Engine/Sources|Источники]] для проверки llms-файла и загрузки.
- Использует [[Engine/SafeHttp|Безопасный HTTP-клиент]] для запросов к реестрам.
- Вызывается из `DocsEngine` (`api.rs`) при `resolve` и `POST /libraries`.

## Ограничения и важные детали

- Slug библиотеки берётся из GitHub-метаданных (`/owner/repo`). Для сайта без репозитория — из host и пути.
- Сайт, указанный в метаданных, не сохраняется, если это ссылка на GitHub: она становится репозиторием.
- Если репозиторий не найден, пишется предупреждение, источник не создаётся.
- Алиас — имя, по которому искали, в нижнем регистре. Он попадает в поиск по точному совпадению.
- Для сайта с llms-файлом источником становится llms; обход сайта не запускается.

## Решения и основания

- Сайт индексируется, даже если есть репозиторий. Основание: комментарий в `register` — в репозиториях часто только README, поэтому результаты могут повторяться.
- Не более трёх кандидатов. Основание: константа `MAX_CANDIDATES`; причина не задокументирована.
