# BarkDocs — База знаний

BarkDocs — бэкенд для ИИ-агентов: находит библиотеку, скачивает её документацию из GitHub, llms.txt или сайта, индексирует в PostgreSQL FTS и отдаёт фрагменты через HTTP API и MCP-сервер.
Стек подтверждён манифестами: Rust (edition 2024), axum 0.8, sqlx 0.9, PostgreSQL 17, Docker Compose.

## Обновление памяти

Заметки отражают текущее состояние проекта. При изменении контракта, потока, зависимости или ограничения обновляй затронутую заметку и `Architecture.md`; неверные сведения удаляй.
Имена файлов и папок доменов — на английском. Changelog и дневники задач не ведутся: история изменений хранится в git.
