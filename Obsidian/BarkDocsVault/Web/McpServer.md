# MCP-сервер

Parent: [[Index]]

## Назначение

MCP-сервер в транспорте Streamable HTTP без сессий. Даёт агентам два инструмента поверх [[Engine/DocsEngine|движка]]. Подключён в [[Web/Gateway|шлюзе]] на `POST /mcp`, поэтому проверка ключа выполняется до него.

## Источники

| Файл | Значимый символ | Роль |
|------|-----------------|------|
| `backend/barkdocs-web/src/mcp.rs` | `handle` | Разбор JSON-RPC, маршрутизация методов, проверка `Origin` |
| `backend/barkdocs-web/src/mcp.rs` | `initialize`, `tools_list` | Согласование версии протокола, описание инструментов |
| `backend/barkdocs-web/src/mcp.rs` | `tools_call`, `engine_json` | Вызов движка и обработка ошибок |
| `backend/barkdocs-web/src/mcp.rs` | `format_libraries`, `format_docs` | Текст ответа для агента |

## Публичные контракты

| Контракт | Поведение и условия |
|----------|---------------------|
| Методы `initialize`, `ping`, `tools/list`, `tools/call` | Остальные методы — JSON-RPC ошибка `-32601` |
| `resolve-library-id` (`libraryName`) | Ищет библиотеку; при отсутствии в индексе движок опрашивает реестры |
| `query-docs` (`libraryId`, `query`) | Фрагменты документации; формат — заголовок, источник и текст каждого фрагмента |

Версии протокола: `2025-11-25`, `2025-06-18`, `2025-03-26`. Неизвестная версия согласуется как самая новая.
Ошибки инструмента возвращаются внутри результата с `isError: true`. Отсутствие обязательного аргумента — JSON-RPC ошибка `-32602`.

## Зависимости и взаимодействия

- Вызывает [[Engine/DocsEngine|DocsEngine]] через `GET /libraries/resolve` и `GET /docs` с каналом `mcp` и владельцем ключа: запросы попадают в [[Engine/Usage|учёт]].
- Не имеет собственной авторизации: доступ даёт шлюз.

## Ограничения и важные детали

- Уведомления (без `id`) получают 202 без тела.
- `GET /mcp` не обслуживается и отвечает 405: потока событий нет.
- Запрос с заголовком `Origin` получает 403. Браузерные клиенты не поддерживаются.

## Решения и основания

- Режим без сессий и JSON-ответы на каждый POST. Основание: комментарий в `mcp.rs` — спецификация допускает такой режим.
- Отказ на `Origin`. Основание: комментарий в `mcp.rs` — защита от DNS rebinding не нужна агентам, а браузерные клиенты не поддерживаются.
