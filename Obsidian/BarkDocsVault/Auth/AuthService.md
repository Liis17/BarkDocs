# AuthService

Parent: [[Index]]

## Назначение

Выдача, проверка и отзыв API-ключей сервиса `barkdocs-auth`. Ключ имеет вид `bd_` и 64 hex-символов. В БД хранится только SHA-256 ключа. Admin-ключ берётся из `ADMIN_KEY`, сравнивается по хешу и в БД не записывается.

## Источники

| Файл | Значимый символ | Роль |
|------|-----------------|------|
| `backend/barkdocs-auth/src/main.rs` | `verify` | Проверка ключа, возвращает роль |
| `backend/barkdocs-auth/src/main.rs` | `create_key`, `list_keys`, `revoke_key` | Управление ключами, только admin |
| `backend/barkdocs-auth/src/main.rs` | `require_admin`, `hash_key`, `generate_key` | Проверка admin-ключа, хеширование, генерация |
| `backend/barkdocs-auth/migrations/0001_init.sql` | `api_keys` | Хранение ключей в схеме `auth` |

## Публичные контракты

Адрес по умолчанию `0.0.0.0:8081`, переопределяется `BIND_ADDR`.

| Контракт | Поведение и условия |
|----------|---------------------|
| `POST /verify` (Bearer) | 200 с `{"role": "admin"}` или `{"role": "user"}`; 401, если ключ неизвестен или отозван |
| `POST /keys` (admin, `{"name"}`) | 201 с ключом в ответе. Ключ показывается один раз; пустое имя — 422 |
| `GET /keys` (admin) | Список ключей без хешей |
| `DELETE /keys/{id}` (admin) | 204. Повторный отзыв или неизвестный id — 404 |
| `GET /healthz` | `ok` |

## Зависимости и взаимодействия

- Вызывается [[Web/Gateway|Публичным шлюзом]] через `POST /verify` при каждом запросе.
- Использует собственную схему `auth` в PostgreSQL; миграции применяются при старте.

## Ограничения и важные детали

- Сервис не стартует без `ADMIN_KEY` длиной не менее 32 символов.
- Отзыв мягкий: строка остаётся, заполняется `revoked_at`.
- В `docker-compose.yml` порт открыт только на `127.0.0.1`, поэтому управление ключами доступно с хоста.

## Решения и основания

- Хранится только хеш ключа. Основание: комментарий в `main.rs` — «В БД хранится только sha256 ключа, сам ключ показывается один раз при создании».
- Admin-ключ не хранится в БД. Основание не задокументировано; в коде указано только сравнение с хешем из окружения.
